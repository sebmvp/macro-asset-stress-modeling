## Underlying sources (as reported by Kaggle)

- Asset prices: Yahoo Finance / `yfinance`
- Macro indicators: FRED / `pandas-datareader`

## Project sample

The analysis used 4,150 daily observations from 2014-10-17 through
2026-02-25. The public extract may continue to be updated. The code
restricts to that historical window after download.
